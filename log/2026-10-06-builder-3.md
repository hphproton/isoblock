## Done

- **Patch files** (`src/core/patch/`): JSON Patch (RFC 6902: add, remove, replace, move, copy, test) and the short commands `move`, `rot`, `set`, `lock`, `relate`, with `#` comments; the first comment line is the description. `solve` in a patch is `E_USAGE` naming stage 4. The file is parsed first, then applied.
- **Application:** each step returns new data, so a patch is atomic and the input scene is never changed (a test freezes it). `move` and `rot` round computed coordinates to 6 decimals; `rot` keeps the footprint center; every `assumptions[].value` follows the value at its path; `set ... note=` edits the note of the assumption with that path.
- **Locks:** `touchedLocks` follows SPEC 12 (value change, vanished lock entry, vanished object; only the original locks count; labels in object order, then lock order). The order of outcomes is fixed in `runPatch`: failing patch (`E_PATCH`, `E_USAGE`), then locks (`E_LOCK`, exit 3), then schema and references of the result (`E_SCHEMA`, `E_REF`), else applied. New error codes `E_PATCH`, `E_LOCK`; exit code 3.
- **CLI `patch`** with `-o`, `--dry-run`, `--json`; text and JSON report; a rejected or invalid patch writes no scene file; the patch log `<output without .json>.log.jsonl` gets one line for an applied or lock-rejected patch that is not a dry run.
- **CLI `diff`** (text and `--json`) and the core `diffScenes`: items matched by identity (`id`; `path` for assumptions), everything else one value, entries sorted by code point.
- **CLI `compare`** with patch and scene variants, 1 to 4 variants, formats `text`, `md`, `json`. `--state` names stage 6; `--render` is not scheduled.
- `Io` gained `appendText` and `exists` (for the log) and moved to `src/cli/io.ts` (still exported from `run.ts`). The old tests that said `patch`, `diff` and `compare` were unavailable were replaced.
- `docs/AGENT_GUIDE.md` covers the patch syntax, `patch`, `diff` and `compare`; every example in it was run with the built tool. `CHANGELOG.md` is updated under `Unreleased`. All Stage 3 tasks in `ROADMAP.md` are ticked.

Not touched: `SPEC.md`, `AGENTS.md`, `MAINTAINING.md`, `tests/golden/`, `tests/fixtures/`, `package.json`. The scene file format did not change and no fixture needed a change. No new dependency.
