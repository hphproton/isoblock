## Scope

The owner chose the next stage from a list of candidates that the maintainer drew up: the editor first, because a person who edits scenes on the editor page cannot add an object there yet. Stage 11 adds to the editor: Add, Duplicate, Delete, nudging with the arrow keys, a state switch, hiding an object per state, and settling an assumption. It adds to the CLI what the editor edits need, or what was left from stage 10: the short commands `hide` and `show`, `check --failing`, and `solve --patch -`.

## Decisions

- Every editor edit is defined by a short command (SPEC 10, Edits): it changes the scene exactly as that command would, and it is refused, with a notice, when `patch` with that command would exit 2 or 3. So Delete is `remove`: a locked object, an object a check names and an index shift are refused for the reasons `remove` gives. The saved file of an edit can be compared byte for byte with the file `patch` writes.
- Add places the object at the ground point under the center of the view region, snapped to the grid step. The point depends on the scene only, not on the size of the window, so an editor case has one expected file.
- Duplicate places the copy next to the original along u, by the extent of its footprint, and copies only `type` and `rot`: a copy with the locks, relations or `hide` entries of the original would be a second object bound to the first one's constraints without anyone deciding so.
- `hide` creates the state when it is missing, so that an agent can add a state with one command; `show` leaves an empty list rather than removing the state. The editor shows checkboxes for the existing states only.
- Settling an assumption is a person's act: the editor removes an entry only after `Settle` and `Confirm`, and no patch command removes one. Q-006 keeps its answer for editing a number and records the change.
- Controls are specified by their accessible names, so that people with assistive technology and test scripts find them the same way.
- The new fixtures are in new directories (`tests/fixtures/hide/`, `tests/fixtures/editor/`): the object patch test of release 0.10.0 counts the files in `tests/fixtures/objects/`, and the suite of `main` passes unchanged on this branch.
- SPEC 16: the editor guide is 1,500 to 2,500 lines (1,744 now).
