## Scope

The old stage 6 (states, `sort_consistency` and slicing, `reachable`, `capacity`) is split in two:

- **Stage 6:** states that hide objects, `--state` for `check`, `render`, `compare` and `export --target gen-bbox`, and the checks `reachable`, `capacity` and `min_screen_size`. Core and CLI only.
- **Stage 7:** `sort_consistency` and slicing, the runtime file with states and slices, and the Godot adapter's states, `instantiate` by type and sorting of moving objects.

Reasons: the old stage 6 was larger than any earlier stage, and adding states to the runtime file now would change the expected files of stage 5 before a builder could follow, which would leave `main` failing between the merge of this opening and the end of the stage. Stage 7 changes the runtime file once, for states and slices together.
