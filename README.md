# IsoBlock

IsoBlock keeps the layout of a 2D isometric scene as data in world units. People and AI agents edit it together; the tool checks the scene's rules; one approved layout file feeds the engine, image-generation pipelines and graybox gameplay.

Status: pre-release (0.x). Progress by stage: `ROADMAP.md`.
